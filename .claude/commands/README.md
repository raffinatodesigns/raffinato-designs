# Raffinato Designs — Shared Skills

Add custom Claude Code slash commands here as `.md` files.

Any skill added to this folder is available to everyone working in this project.

## How to use
- Run a skill: `/skill-name` in the Claude Code prompt
- Skills live in this folder as `.md` files (e.g., `new-client.md` → `/new-client`)

## How to add a skill
Create a `.md` file here. The filename becomes the slash command.

Example — `new-client.md`:
```
Create a new client folder under /clients with the standard structure:
- contract.md
- brief.md
- assets/
Then open hvac-website.html as a template reference.
```
